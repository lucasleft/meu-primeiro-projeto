# Skills de Motion Graphics

Skills (formato Agent Skills / `SKILL.md`) instaladas neste projeto para o Claude Code
carregar automaticamente ao trabalhar com animação e motion graphics.

| Origem (MIT) | Commit | Skills |
|---|---|---|
| [greensock/gsap-skills](https://github.com/greensock/gsap-skills) (oficial GSAP) | aed9cfd | gsap-core, gsap-timeline, gsap-scrolltrigger, gsap-plugins, gsap-react, gsap-frameworks, gsap-utils, gsap-performance |
| [notedit/happy-skills](https://github.com/notedit/happy-skills) (vídeo com Remotion) | 9a2d593 | video-producer, gsap-animation, spring-animation, react-animation |
| [iart-ai/web-animation-skills](https://github.com/iart-ai/web-animation-skills) | b6dba3e | gsap-web, svg-animation, lottie-animation, micro-interaction, page-transition-animation, 60fps-animation, accessible-animation, ascii-animation, glassmorphism |

Licenças originais em `.claude/skill-licenses/`.

Para atualizar: clone o repositório de origem e copie a pasta da skill por cima da daqui.
